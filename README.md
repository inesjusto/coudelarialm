# Coudelaria Lima Monteiro

## Descrição do Projeto

Este projeto foi desenvolvido no âmbito da Prova de Aptidão Profissional e consiste num website para a Coudelaria Lima Monteiro.
A plataforma inclui uma área pública, onde os visitantes podem consultar informações sobre a coudelaria, serviços, cavalos disponíveis e contactos, e uma área administrativa reservada, destinada à gestão interna da coudelaria.
Na área administrativa é possível gerir cavalos, clientes, fornecedores, aulas, alugueres, despesas e vendas de cavalos. O sistema permite ainda gerar relatórios financeiros em PDF e faturas associadas à venda de cavalos.

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- PDO
- Chart.js
- Dompdf
- PHPMailer
- XAMPP / Apache

## Funcionalidades Principais

- Website público informativo
- Listagem de cavalos disponíveis
- Filtros por sexo dos cavalos
- Formulário de contacto
- Área administrativa com login
- Gestão de cavalos
- Gestão de clientes
- Gestão de fornecedores
- Gestão de aulas
- Gestão de alugueres
- Gestão de despesas
- Gestão de vendas de cavalos
- Dashboard com estatísticas e gráficos
- Exportação de relatório financeiro em PDF
- Criação de fatura de venda de cavalo em PDF
